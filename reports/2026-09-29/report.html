30 Sept 2026
1 days		Microsoft Entra Connect Sync minimum version

Connect Sync installations below version 2.5.79.0 will stop synchronizing when the minimum-version requirement takes effect.

Upgrade to the latest supported Connect Sync release and validate synchronization, connector health, and recovery procedures. Do not treat installation of the minimum version alone as a durable fix.

Customer applicability: Not assessed.

30 Sept 2026
1 days		Azure Functions v3 on Linux Consumption

Functions v3 applications on the Linux Consumption plan stop running after the cutoff.

Migrate affected applications to Functions v4 with supported language runtimes. Validate triggers, bindings, dependencies, deployment settings, and production behavior before switching traffic.

Customer applicability: Not assessed.

30 Sept 2026
1 days		Azure Virtual Desktop classic

The classic Azure Virtual Desktop service reaches retirement. Classic deployments must not be treated as equivalent to supported modern Azure Virtual Desktop resources.

Migrate classic tenants and host pools to the current Azure Virtual Desktop service. Validate user assignments, profiles, application availability, networking, and client access.

Customer applicability: Not assessed.

30 Sept 2026
1 days		VPN Gateway VpnGw1–VpnGw5 non-AZ SKUs

The non-AZ VpnGw1 through VpnGw5 SKU family reaches its announced retirement date and requires migration to supported AZ SKUs.

Use the current documented manual migration guidance to move affected gateways to appropriate AZ SKUs. Plan and test connectivity, gateway addressing, capacity, and any required maintenance window.

Customer applicability: Not assessed.

30 Sept 2026
1 days		Container insights ContainerLog schema

The legacy ContainerLog table stops receiving new container log data. Queries and alerts that continue to depend on fresh ContainerLog records can lose visibility.

Enable or confirm ContainerLogV2 collection and update KQL queries, alerts, workbooks, exports, and downstream consumers for the new schema. Validate ingestion and alert behavior.

Customer applicability: Not assessed.

30 Sept 2026
1 days		Legacy Service Bus SDKs and SBMP

Support ends for the listed legacy Service Bus SDKs, while SBMP communication becomes unusable. SDK support retirement and protocol shutdown are different effects.

Replace WindowsAzure.ServiceBus, Microsoft.Azure.ServiceBus, and com.microsoft.azure.servicebus dependencies in affected Service Bus applications with current Azure SDKs using AMQP. Test authentication, retries, settlement, transactions, and message handling.

Customer applicability: Not assessed.

30 Sept 2026
1 days		Azure API for FHIR

Azure API for FHIR reaches retirement. Existing applications need a supported FHIR destination rather than continued reliance on the retired service.

Migrate to the FHIR service in Azure Health Data Services using an appropriate migration strategy. Validate data completeness, identities, permissions, integrations, search behavior, and cutover recovery.

Customer applicability: Not assessed.

1 Oct 2026
2 days		Azure SQL Database Fsv2 hardware

Fsv2 hardware reaches its announced retirement date; remaining affected databases are scheduled for automatic migration under the retirement plan.

Choose and validate an appropriate General Purpose standard-series Gen5 or Hyperscale premium-series configuration. Review performance, compatibility, capacity, and cost before relying on a scheduled automatic move.

Customer applicability: Not assessed.

1 Oct 2026
2 days		Azure Databricks Standard tier

Automatic upgrades of Standard-tier workspaces to Premium begin, creating a pricing and governance change that requires review.

Review affected workspaces, Premium pricing, budgets, policies, and operational dependencies. Plan any proactive tier transition and verify the final workspace configuration.

Customer applicability: Not assessed.

1 Oct 2026
2 days		Azure AI Anomaly Detector

Anomaly Detector reaches service retirement; applications must move away from its endpoints.

Evaluate suitable Microsoft Fabric capabilities or open-source alternatives. Rebuild and validate detection pipelines, model quality, operating thresholds, monitoring, and integration behavior.

Customer applicability: Not assessed.

13 Oct 2026
14 days		General-purpose v1 and legacy BlobStorage accounts

Remaining affected general-purpose v1 and legacy BlobStorage accounts are subject to in-place conversion to general-purpose v2. The conversion is permanent and can change transaction costs.

Review the documented conversion scope, workload transaction mix, access tiers, and projected pricing. Upgrade deliberately where appropriate and verify account settings and application behavior after conversion.

Customer applicability: Not assessed.

13 Oct 2026
14 days		Windows Server 2012 and 2012 R2 ESU

The Extended Security Updates period ends for Windows Server 2012 and 2012 R2. Continued operation is not equivalent to a supported, security-updated operating system.

Upgrade or migrate workloads to a supported Windows Server release and validate application compatibility, backup, recovery, and licensing. Confirm any exceptional entitlement independently.

Customer applicability: Not assessed.
